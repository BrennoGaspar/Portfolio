# 🚀 Brenno Gaspar | Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e principais projetos na área de tecnologia.
O objetivo do projeto é centralizar minhas experiências, tecnologias e soluções desenvolvidas ao longo da minha jornada como desenvolvedor Full Stack em um único site pessoal.

---

## ✨ Sobre o Projeto

O portfólio foi desenvolvido com foco em:

- Design moderno e responsivo
- Animações fluidas
- Experiência do usuário (UI/UX)
- Performance e organização de código (sections e components)
- Identidade visual profissional

Além de apresentar meus projetos, o site também possui uma seção de contato integrada para networking e oportunidades profissionais.

---

## 🛠️ Tecnologias Utilizadas

- TypeScript
- Next.js
- React.js
- Tailwind CSS
- Framer Motion
- Lucide React

---

## 📌 Funcionalidades

- ✅ Navbar responsiva
- ✅ Divisão em sections e components para reutilização e limpeza de código
- ✅ Grid dinâmica de projetos
- ✅ Cards interativos com hover effects
- ✅ Formulário de contato funcional
- ✅ Layout totalmente responsivo

---

## 🎨 Design

O projeto segue uma identidade visual moderna em Dark Mode, utilizando:

- Tons escuros minimalistas
- Azul neon suave como cor primária
- Efeitos de blur e glow
- Componentização reutilizável
- Layout inspirado em portfolios premium e interfaces modernas
